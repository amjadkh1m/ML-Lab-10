# SVM Classification - Lab 10

##  Overview
This project demonstrates how to use the Support Vector Machine (SVM) algorithm for classification using the Iris dataset.

##  Dataset
The dataset used is the Iris dataset, which contains 150 samples with 4 features:
- Sepal length
- Sepal width
- Petal length
- Petal width

The target variable consists of 3 classes:
- Setosa
- Versicolor
- Virginica

##  Technologies Used
- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn

##  Steps

1. Import libraries
2. Load dataset
3. Split data into training and testing sets
4. Train SVM model
5. Make predictions
6. Evaluate model using:
   - Accuracy
   - Classification Report
   - Confusion Matrix
7. Compare different kernels (Linear vs RBF)

##  Results
The model achieved high accuracy on the test dataset. Different kernels were tested to compare performance.

##  Conclusion
SVM is an effective classification algorithm, especially for small and medium datasets like Iris. Kernel selection can impact model performance.
